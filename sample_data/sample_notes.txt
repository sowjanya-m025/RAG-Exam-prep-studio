Introduction to Machine Learning - Lecture Notes

1. What is Machine Learning?
Machine learning is a field of computer science in which algorithms learn patterns from data instead of being explicitly programmed. A model is trained on examples and then used to make predictions on new, unseen data. The quality of a model is judged by how well it generalizes beyond its training data.

2. Supervised Learning
In supervised learning the training data contains labeled data: every example has an input and a known correct output. The two main tasks are classification, where the output is a category such as spam or not spam, and regression, where the output is a continuous number such as house price. Common algorithms include linear regression, logistic regression, decision trees and support vector machines.

3. Unsupervised Learning
Unsupervised learning works with unlabeled data and tries to discover hidden structure. Clustering groups similar examples together, for instance customers with similar buying habits. K-means is a popular clustering algorithm that assigns each point to the nearest of k centroids and then updates the centroids until they stop moving. Dimensionality reduction, such as principal component analysis, compresses data while keeping most of its variance.

4. Overfitting and Underfitting
Overfitting happens when a model learns the noise and quirks of the training set so well that it performs poorly on new data. Underfitting happens when a model is too simple to capture the real pattern, so it performs badly even on the training data. Overfitting can be reduced with more training data, regularization, cross-validation, early stopping and simpler models. The bias-variance tradeoff describes this balance: high bias causes underfitting and high variance causes overfitting.

5. Gradient Descent
Gradient descent is an optimization algorithm that minimizes a loss function by repeatedly moving the model parameters in the direction opposite to the gradient. The learning rate controls the size of each step. If the learning rate is too large the algorithm may overshoot and diverge, and if it is too small training becomes very slow. Stochastic gradient descent updates the parameters using a single example or a small mini-batch, which is faster and noisier than using the full dataset.

6. Evaluating Models
Accuracy is the fraction of predictions that are correct, but it can be misleading on imbalanced datasets. Precision is the fraction of predicted positives that are truly positive, while recall is the fraction of actual positives that the model finds. The F1 score is the harmonic mean of precision and recall. A confusion matrix shows true positives, false positives, true negatives and false negatives in one table. Data is usually split into training, validation and test sets so that the final test set gives an honest estimate of performance.

7. Neural Networks
A neural network is made of layers of connected units called neurons. Each neuron computes a weighted sum of its inputs and passes it through a non-linear activation function such as ReLU or sigmoid. Training uses backpropagation, which applies the chain rule to compute the gradient of the loss with respect to every weight, and then gradient descent to update them. Deep learning refers to networks with many hidden layers, which can learn hierarchical features from raw data such as images and text.
